# CiteSight Content Recommendation Templates Guide

## Overview
CiteSight offers 6 content optimization templates designed to improve your content's visibility across different AI models. Each template is specifically tailored to match how different AI systems process, understand, and cite content.

---

## 🌐 Universal Template (Base)
**Best For:** General content optimization across all AI models

### What It Does:
- Creates comprehensive content optimized for all major AI models
- Focuses on universal best practices that work across ChatGPT, Perplexity, Claude, LLaMA, and DeepSeek
- Provides balanced recommendations suitable for any AI-powered search or chat system

### Optimization Focus:
1. **Content Headers**
   - Clear H1 tags with primary keyword (40-60 characters)
   - Action-oriented language
   - Example: "Complete Guide to [Keyword]: Everything You Need to Know"

2. **Subject Lines**
   - Primary keyword at the beginning
   - Under 60 characters
   - Uses numbers/lists and creates urgency
   - Example: "[Keyword] 2025: Top 10 Expert-Recommended Options"

3. **Body Content Structure**
   - Introduction (100-150 words)
   - Problem/need identification
   - Solutions with comparisons
   - Expert recommendations
   - Actionable conclusion
   - Target: 1500-2500 words

4. **Credibility Signals**
   - Author expertise and credentials
   - Publication and update dates
   - Sources and citations
   - Expert quotes
   - Statistical data

5. **FAQs**
   - 5-10 frequently asked questions
   - Matches search intent
   - Concise answers (50-100 words)

6. **Schema Markup**
   - Article, FAQPage, BreadcrumbList, Organization schemas

7. **Keyword Optimization**
   - Primary keyword density: 1-2%
   - LSI keywords and synonyms
   - Natural placement in headers and body

## 💬 ChatGPT Template
**Best For:** OpenAI's GPT models (ChatGPT, GPT-4)

### What It Does:
- Optimizes content for ChatGPT's conversational and question-answering style
- Focuses on logical information flow with clear explanations
- Uses analogies, examples, and structured formats that GPT models prefer

### Specific Optimization:
- **Tone:** Conversational yet authoritative
- **Structure:** Question-answer format
- **Key Factors:**
  - Clear, logical flow of information
  - Use of analogies and examples
  - Direct answers to common questions
  - Structured lists and bullet points
  - Definition of technical terms

### Best Practices:
- Include 'What', 'Why', 'How' sections
- Use comparison tables
- Add step-by-step guides
- Include practical examples
- Define acronyms and jargon upfront

**Example Use Case:** How-to guides, tutorials, educational content, product comparisons

## 📊 How Recommendations Are Generated

### Process Flow:
1. **Content Analysis:** The system analyzes your content title, body, and keyword
2. **Template Selection:** You choose which AI model to optimize for
3. **AI Generation:** OpenRouter GPT-4o generates specific recommendations based on the template guidelines
4. **Comprehensive Output:** You receive:
   - Optimized header
   - SEO-optimized subject line
   - Body improvements (with before/after)
   - Credibility signals to add
   - FAQs (5-10 questions with answers)
   - Schema markup suggestions
   - Semantic chunks for better AI parsing
   - Keyword optimization tips
   - Implementation priority list

### Recommendation Categories:

#### 1. **Optimized Header**
A rewritten H1 that follows the template's specific guidelines for maximum AI visibility

#### 2. **Subject Line**
An SEO-optimized title for meta descriptions and search results

#### 3. **Body Improvements**
Section-by-section recommendations showing:
- Current text
- Recommended replacement
- Reason for the change

#### 4. **Credibility Signals**
Specific additions to boost trust:
- Author credentials to add
- Citation types needed
- Data sources to include
- Priority level (high/medium/low)

#### 5. **FAQs**
AI-generated questions and answers that match:
- Common search queries
- User intent
- The specific AI model's preference for Q&A format

#### 6. **Schema Markup**
JSON-LD schema suggestions for:
- Article schema
- FAQPage schema
- BreadcrumbList
- Organization

#### 7. **Semantic Chunks**
Content broken into logical sections (300-500 words each) that AI models can easily parse and cite

#### 8. **Keyword Optimization**
- Current vs. recommended keyword density
- LSI keywords to include
- Placement improvements

#### 9. **Implementation Priority**
Ranked list of changes by:
- Impact (high/medium/low)
- Effort (high/medium/low)

## 🚀 How to Use

1. **Create Content:** Add your content in Content Management
2. **Navigate to Recommendations Tab:** Select your content
3. **Choose Template:** Select the template that matches your target AI audience
4. **Generate:** Click "Generate Recommendations" (takes 10-20 seconds)
5. **Review:** Check all recommendations
6. **Apply:** Click "Implement All" to automatically apply changes

---

## 💡 Pro Tips

### 1. **Use Multiple Templates**
Generate recommendations from multiple templates to see different approaches:
- Start with Universal for baseline
- Then try ChatGPT or Perplexity for specific optimizations

### 2. **Keyword Analysis First**
Run Keyword Analysis before generating recommendations to get:
- Related questions to address
- Keyword difficulty insights
- Search intent data
- These feed into better recommendations

### 3. **Review Before Applying**
The "Implement All" button automatically updates your content. Review the modal carefully before confirming.

### 4. **Iterative Optimization**
- Apply recommendations
- Test AI visibility
- Refine based on results
- Re-optimize with different template

### 5. **Combine with Manual Edits**
Use recommendations as a guide, but add your unique expertise and voice.

## ⚠️ Important Notes

- **Processing Time:** Recommendations take 10-30 seconds to generate (AI API call)
- **Content Length:** Works best with content 500+ words
- **Keyword Required:** More accurate with a target keyword specified
- **Auto-Update:** "Implement All" overwrites current content (review carefully)
- **Template Mixing:** Can apply different template recommendations sequentially

## 🔧 Troubleshooting

### "Error applying recommendations"
- Check backend logs: `/var/log/supervisor/backend.err.log`
- Verify OpenRouter API key is valid
- Ensure content exists in database

### Recommendations seem generic
- Make sure your content has enough substance (500+ words)
- Add a specific keyword for context
- Try a model-specific template instead of Universal

### Taking too long
- Normal response time: 10-30 seconds
- OpenRouter API may be slow during peak times
- Check internet connectivity and API status
